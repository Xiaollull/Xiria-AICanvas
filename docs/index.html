What it is

XiriaCanvas AI runs entirely on your own machine. The same source tree supports Windows and Linux, and the project does not depend on ComfyUI or Stable Diffusion WebUI at runtime: it does not read, import, upgrade or modify either of them, or their environments.

One installer sets up an isolated Python environment, picks a PyTorch build that matches your GPU driver, and serves a web UI on your own network. Everything below is the manual for that program. Maintainer and troubleshooting material lives in the wiki.

Engines

Six engines are selectable in Generate. They share one prompt grammar, one sampler vocabulary, and one gallery, and differ in how a model is assembled and how guidance is applied.

EngineModelComponents
SDStable Diffusionone checkpoint
iLIllustrious / SDXLone checkpoint
Animanative Flow Matchingdiffusion model + text encoder + VAE
FluxFLUX.1, distilled guidancediffusion model + CLIP-L + T5-XXL + VAE
Flux2FLUX.2, large-model guidancediffusion model + text encoder + VAE
Krea2Krea 2 single-stream DiTdiffusion model + text encoder + VAE

SD and iL mount one checkpoint file. The four native engines mount their parts separately, so a text encoder or VAE can be shared between models instead of being duplicated inside every checkpoint. FLUX.1 is the only engine that takes two text encoders. For FLUX.1, FLUX.2 and Krea 2 the diffusion model may be a .safetensors or a .gguf file; see file formats.

Both FLUX generations are guidance distilled: they have no unconditional branch, so the negative prompt carries nothing and is not sent. What you typed stays in the box for the other engines. Krea 2 is the one native engine that is not distilled and keeps a working negative prompt.

Guidance support follows the same split. PAG is available for SD, iL and native Anima; CFG-Zero* is available for native Anima and Krea 2. Neither applies to either FLUX generation.

Quick start

The one-line command is the same on both operating systems. It opens a local visual configuration window that detects your GPU before installing anything.

npm run setup   # first time only
npm start       # afterwards

Windows: double-click Setup-XirAI.bat, then Start-XirAI.bat.
Linux: run sh Setup-XirAI.sh, then sh Start-XirAI.sh, or mark the two .desktop files as trusted and double-click them.

The configuration window is always served at http://localhost:7709/config. Until setup and build verification finish, the main application is locked and / redirects there. Full detail is on the installation page.
