01

你的模型，只留在你的机器上。

XiriaCanvas AI 创建独立、可验证的运行环境，不会读取、升级或修改 ComfyUI 与 Stable Diffusion WebUI。

01

隔离安装

安装器自动选择兼容的 PyTorch，并把所有 Python 依赖限制在项目内部。

02

本地处理

提示词、模型与生成图片都留在主机上，除非你主动移动它们。

03

一个模型库

02

从克隆到画布。

可视化配置器会先检查 GPU，再开始下载；支持断点续传，并通过真实 CUDA 运算验证环境。

查看完整安装说明 →
终端
# 仅首次运行
npm run setup

# 配置完成后的每次启动
npm start

Windows 也可以直接使用配套的 .bat；Linux 提供 Shell 与桌面入口。
