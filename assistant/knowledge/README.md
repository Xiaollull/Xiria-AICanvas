# 知识库（占位）

本目录为 AI 助手的知识库预留，**当前版本尚未实现检索**。

助手现在只会把所选角色（persona）的 `systemPrompt` 发送给模型。本目录中的任何文件都不会被读取、
索引或发送到服务商。

## 现状

- 设置结构中已保留 `knowledgeIds` 字段，并在请求组装阶段保留了 `【知识库】` 段落的插入位置
  （见 `src/ai-assistant-protocol.js` 的 `composeSystemPrompt`）。
- 因此后续接入检索时，只需要填充该数组，不需要改动系统提示词的结构或存储格式。

## 后续接入时的预期形态

```
assistant/knowledge/
  <collection>/
    *.md          # 纯文本片段
    index.json    # 分块与向量索引（由后续版本生成）
```

在检索落地之前，请不要在此放置任何敏感内容：该目录尚无访问控制，也没有内容过滤。
